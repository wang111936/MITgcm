## 3. P5-I01 deterministic input result

The generator produced 313 files for the frozen 8 by 6 by 2 Cartesian
experiment, including 97 exact endpoint records from 0 through 86400 s,
native C-grid U/V fields, Stokes and EXF wind, temperature/nutrient fields,
three locked particles, all required namelists, the manifest and SHA-256
inventory.

The independent decoder performed 299 binary-field checks and verified the
dimensions, ordering, IEEE binary64 precision, big-endian encoding, record
times, affine values, particle schema, reference locks, configuration tokens
and every checksum before model start. It also enforces a consistent generic
r-coordinate namelist (`delR`, `viscAr`, `diffKrT`, `diffKrS`).

## 4. Defects found and resolved during admission

Earlier attempts are preserved as failed diagnostic evidence and are not
accepted as P5.1 results:

1. `p51-exact-189115099-attempt01` exposed a production compile defect when
   DIAGNOSTICS and BOM were enabled together. `BOM_EVENT_TRANSACTION` now
   includes `PARAMS.h`, which declares the runtime diagnostics switch.
2. `p51-exact-6853ea3f8-attempt02` completed all builds but exposed an invalid
   gate assumption that package group `gfd` creates `ALLOW_GFD`. The audit now
   checks the actual generated GFD capability macros and key objects.
3. `p51-exact-ffff51df0-attempt03` reached the real model and exposed mixed
   z/r-coordinate namelist names. After conversion to generic r-coordinate
   names, a focused run completed normally. The same probe showed that this
   multi-tile build writes a tiled pickup family, so the gate now accepts and
   compares the complete family instead of assuming single-CPU I/O.

All corrections were incorporated before the fresh, clean attempt04 pass.
