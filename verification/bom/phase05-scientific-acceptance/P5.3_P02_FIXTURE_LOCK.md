# MITGCM-BOM P5-P02 convergence-fixture lock

Status: **LOCKED BEFORE THE FIRST CLEAN EXACT-HEAD P5.3 CANDIDATE**

P5-P01 remains exactly Case J.  P5-P02 uses the same grid, particles,
parameters, equation mode and 86,400 s interval, but uses the dedicated smooth
affine functions in `p53_p02_affine_fields.csv` at all three production step
sizes and in the independent reference.

This separation was fixed after a non-candidate calibration run showed that
Case J's 900 s RK4 truncation error was already about `1e-10 m`, four orders of
magnitude below the frozen `1e-6 m` binary64 comparison floor.  At that scale,
the required strict ordering is controlled by output roundoff and cannot test
temporal convergence.  No production source change, reference-derived expected
value, tolerance, norm, step size, precision, ratio threshold, particle, grid,
parameter or integration interval was changed.

The dedicated functions are analytical, affine, smooth, finite and inward over
the admitted domain.  They are a test input, not an expected answer.  The input
generator and independent high-precision oracle both read the same checksummed
coefficient table, then evaluate it through separately implemented paths.  The
independent input auditor reconstructs every native C-grid binary record.

The preliminary high-precision calibration predicted endpoint errors of order
`1e-5` to `1e-4 m` at 900 s and adjacent refinement ratios near 16.  These
figures are design-scale observations only and are not acceptance values.  The
unchanged frozen P5-P02 rules alone decide the exact-head production result.
