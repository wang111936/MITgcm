# MITGCM-BOM P5.3 immutable test contract

Status: **FROZEN BEFORE P5-P01/P5-P02 PRODUCTION EVALUATION**

This file makes the norms and discriminating samples required by the Phase 5
scientific-acceptance plan explicit before any P5.3 production result is
evaluated. It does not amend the equations, tolerances, reference precision,
reference step, or ratio rule frozen in `SCIENTIFIC_ACCEPTANCE_PLAN.md`.

## P5-P01 oracle comparison

- Equation mode: `PAPER2024`.
- Grid, particles, fields, parameters and 86,400 s integration interval:
  exactly Case J.
- Production and independent-oracle RK4 step: 900 s.
- Component bound: `2e-12 + 5e-12*abs(reference)`.
- Position and accumulated-path bound:
  `max(1e-6 m, 5e-11*reference_path)`.
- Predeclared component discriminator: `dv_e` at common time index 1
  (`t=900 s`) for particle 1001.
- Predeclared trajectory discriminator: `x_m` at common time index 96
  (`t=86,400 s`) for particle 1003.
- Each discriminator must differ from locked JULIA mode by more than ten
  times its applicable frozen bound.

## P5-P02 temporal convergence

- Production RK4 steps: 900, 450 and 225 s.
- Common saved times: 0 through 86,400 s at 900 s intervals.
- Independent fine reference: fixed-step RK4 at `900/32 = 28.125 s`.
- Reference arithmetic: Python `decimal` with 90 decimal digits, which
  exceeds 256 binary bits of significand precision.
- Endpoint norm for one particle and one production step: Euclidean position
  error at 86,400 s relative to the fine reference.
- Full-trajectory norm for one particle and one production step: maximum
  Euclidean position error over all 97 common saved times relative to the
  fine reference.
- Floating comparison floor: the frozen absolute position floor, `1e-6 m`.
- Both norms must strictly decrease from 900 to 450 to 225 s for every
  particle.
- For each adjacent refinement, if the coarser norm exceeds
  `50*1e-6 m`, the observed error ratio must be at least 12. Ratios at or
  below that floor are reported but not interpreted.
- No non-finite value, missing sample, unstable particle, stage rejection,
  abnormal termination, or unexpected output file is permitted.

The independent oracle may read only the frozen input coefficient and
particle definitions. It must not import, parse, translate, execute, or copy
`pkg/bom` source and must not consume MITgcm-generated expected values.
