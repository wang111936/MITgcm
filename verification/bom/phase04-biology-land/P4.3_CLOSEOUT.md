# MITGCM-BOM P4.3 local closeout

Status: **LOCALLY COMPLETE; NOT PUSHED OR INTEGRATED**

P4.3 implements only the frozen deterministic birth and distributed event
increment. It does not implement schema-4 trajectory/event output, pickup,
restart, final capacity matrices, P4-G99 or Phase 4 release tagging.

## Accepted scope

- exact Philox4x32-10 with safe 16-bit-limb unsigned multiplication and a
  frozen key of seed, exact parent ID, parent birth count, event index and
  retry attempt;
- deterministic distance-`bomSpringL` placement, WET acceptance,
  BEACHED/OUTSIDE retry, bounded BIRTH_CANCEL and fatal numeric/configuration
  rejection;
- bounded event-metadata allgathers, exact parent-ID ordering, duplicate
  rejection and contiguous positive INTEGER*8 child IDs with overflow checks;
- a single atomic biology/terminal/free-stack transaction that publishes
  death, successful birth and cancellation only after every global, tile,
  event, ID, counter and graph preflight succeeds;
- complete biology owner migration packet schema 3 carrying exact parent ID,
  birth count and S, while the released schema-2 10-integer/6-real layout and
  P4-off packet bytes remain unchanged;
- a production packet validator shared by normal migration and mutation
  tests, with schema/word/count/destination/finite/length rejection before
  owner replacement;
- FINAL slow-manifold refresh plus spring graph/component rebuild on the full
  post-event candidate before authority is changed;
- semantic owner and event records that are byte-identical across serial,
  MPI2, MPI4 and a reversed owner-slot fixture.

Event collectives carry only bounded prospective/accepted birth metadata.
They never gather the live owner set. BOM remains an independent package;
the predecessor `FLT+BOM` case is compatibility-only.

## Findings resolved during implementation

- an initial 23-row candidate gate tested exact Philox only in serial and
  positive schema-3 migration; the frozen plan required MPI2/MPI4 word
  comparison, packet mutation and slot-permutation evidence, so the accepted
  gate was expanded to 26 rows before closeout;
- variable packet widths use contiguous one-dimensional buffers, preventing
  schema-3 strides from altering released schema-2 MPI bytes;
- packet ID decoding now checks high/low-word overflow before multiplication;
- cancellation consumes neither an ID nor a birth count and restores the
  parent's pre-substep S; fatal placement publishes no event or owner change;
- graph/component failures and impossible commit bindings fail before, or
  stop at, guarded internal-consistency boundaries rather than indexing slot
  zero;
- P3 counter additions are overflow-preflighted before transaction commit;
- predecessor collective audits explicitly admit the two fixed-width bounded
  birth-metadata gathers and still reject live-owner gathers.
