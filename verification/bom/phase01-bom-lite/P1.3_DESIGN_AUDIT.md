## 4. Confirmed non-findings

- Ocean velocity is sampled after the ocean step at `(t1,iter1)`, while the
  EXF wind snapshot is the field requested by `LOAD_FIELDS_DRIVER` at
  `(t0,iter1-1)`. The design correctly labels request time rather than claiming
  an EXF source-record timestamp.
- `bomGridWindEast/bomGridWindNorth` do not collide with existing particle
  diagnostics `bomWindEast/bomWindNorth`; both roles remain BOM-owned.
- Requiring `ALLOW_EXF`, `useEXF`, and `useAtmWind` is consistent with the EXF
  compile/runtime structure. Builds without EXF still require a guarded NONE
  path and an explicit EXF-source startup failure.
- P1.3 correctly excludes OpenMP, EXCH2, rotated/curvilinear grids, owner
  migration, Stokes, pickup, and production trajectory output.
- The locked Julia code supports only `water + alpha*wind` as an algebraic
  oracle here; it does not justify fixed-step RK, C-grid, release, owner, or CFL
  behavior.
