## Resolved finding P1.2-A — production diagnostic path

Resolution: **CLOSED**

The frozen lifecycle requires nonzero-particle `BOM_MAIN` to build the P1.2
fields and validate existing particle positions through mapping and wet-pair
interpolation without changing position, ID, status, release time, age, or
owner counts.  It also requires the caller of `BOM_INTERP_WET_PAIR` to stop
with tile, local indices, and wet weight when interpolation is invalid.

The original reviewed `BOM_MAIN` only called `BOM_BUILD_FIELDS`; this caused
the finding.  Functional commit `2f346d98cf978922cae53bff67fc32088cbb8941`
adds the frozen non-moving diagnostic path over current owner records.  It maps
the committed position, calls `BOM_INTERP_WET_PAIR`, and publishes only
`bomI`, `bomJ`, `bomVEast`, and `bomVNorth` after a valid result.  Invalid
results print particle, tile, local-index, ownership, stencil, and wet-weight
context before collective termination.

Verified correction:

1. after field publication, perform a non-moving diagnostic pass over the
   current owner records;
2. map each committed `bomX/bomY` on its current tile, require the frozen owner
   and stencil conditions, and interpolate the authoritative east/north pair;
3. publish only diagnostic `bomI/bomJ/bomVEast/bomVNorth` values after a valid
   result;
4. on failure, print particle/tile context, local indices, and wet weight, then
   terminate collectively;
5. serial and MPI4 positive lifecycle tests prove bitwise preservation of
   authoritative particle state, and caller-level P1-N05 negative tests prove
   the production termination path.

The correction adds no RHS evaluation, RK stages, position updates, release
transitions, owner migration, wind, or Stokes.

## Resolved finding P1.2-B — finite-geometry rejection

Resolution: **CLOSED**

The original implementation checked each individual `delX/delY` value but did
not close all accumulated-span, derived-bound, endpoint, and extreme-periodic
arithmetic cases.  The correction now rejects overflow before accumulation,
validates every derived mapping scalar, checks both endpoints of every stored
face interval, and clears unpublished mapping state before collective failure.
`BOM_NORMALIZE_X` reduces the input and lower bound separately, validates each
intermediate result, and retains the canonical half-open periodic interval.

The frozen contract requires non-finite geometry to stop without publishing
partial mapping state and says any finite equivalent longitude is normalized.
The original P1-N04 matrix covered non-positive spacing and inconsistent bounds
but not non-finite origin/spacing/faces, accumulated overflow, or extreme
finite periodic input; the post-fix matrix covers all of these cases.

Verified correction:

1. validate accumulated spans and every derived mapping scalar before use;
2. explicitly validate both endpoints of every inspected stored face interval;
3. ensure normalization returns an explicit invalid result if periodic
   arithmetic cannot remain finite;
4. focused negative probes cover infinite origin/spacing, accumulated span
   overflow, and an infinite terminal face; positive probes cover both signs of
   `HUGE(oneRL)` on the global longitude domain.
