## 1. 参考审计结论

### 1.1 锁定 Julia 参考

锁定 checkout 处于 detached HEAD `156557359185e4413ce82829f3ed26a4eb8c6283`。其 `Leeway!` 在 equirectangular `(x,y,t)` 插值器上计算水速加经验风偏移；它没有 MITgcm C-grid、tile owner、halo 或湿点归一化语义，也不在 leeway 路径中叠加 Stokes。

因此 Julia 参考只裁决后续 P1.3 的 leeway RHS 和单位换算，不裁决 P1.2 的网格映射、C-grid colocation、周期 owner 或海岸 stencil。P1.2 不复制 Julia 的 cubic 插值器、陆地死亡回调、km/day 单位或 equirectangular 坐标作为生产接口。

### 1.2 MITgcm FLT 参考

- `FLT_MAP_XY2IJLOCAL` 证明规则 Cartesian 和未旋转 spherical-polar 网格可由 `xG/yG` 映射到 C 点整数、面点半整数的局部分数索引；
- `FLT_MAP_IJLOCAL2XY` 提供规则网格反向映射思路；
- `FLT_BILINEAR2D` 不执行 BOM 所需的湿点筛选、湿权重重归一化或显式失败返回；
- FLT 没有 P1.2 所需的完整 360° 经度规范化契约。

BOM 只参考算法，不调用 `FLT_*`，不共享 COMMON、mask 语义、错误路径或文件。

### 1.3 MITgcm 矢量转换

`ROTATE_UV2EN_RL` 的 `kSize=1` 实参仍是五维单层数组。P1.2 必须先把表层 `uVel/vVel` 复制到真正的单层工作数组，再以 `xy2en=.TRUE.`、`switchGrid=.TRUE.`、`applyMask=.TRUE.` 调用；禁止把完整 `Nr` 数组伪装成单层数组。

转换后的 east/north 是固定地理方向的 C 点分量，分别用标量 `EXCH_3D_RL(...,1,myThid)` 更新 halo，不再应用模型网格矢量换向规则。

## 2. 工作包边界

P1.2 包含：

1. 规则 Cartesian 与未旋转 spherical-polar 的全局域界初始化；
2. 完整 360° 球面域的周期经度规范化；
3. 全局原生坐标与 tile 局部 C 点分数索引正反映射；
4. owner 与插值 stencil 可用性分别判定；
5. 表层 C-grid `uVel/vVel` 到 C 点 east/north 场的构造和 halo exchange；
6. 两分量共用权重的湿点归一化双线性插值；
7. 对不支持网格、缺失 stencil、非有限值和湿权重不足的显式失败；
8. 将 P1.1 初值 locator 收敛为新映射接口的兼容包装，保持 P1.1 初始 owner/湿中心判据。

P1.2 不包含：

- 粒子位置推进、RK stage、release-time 分割或 CFL 位移检查；
- EXF 风进入 RHS；
- Stokes 数组、文件、耦合器或运动项；
- tile/rank owner 迁移和开放边界状态转换；
- 时变场 old/new 快照或 stage-time 插值；
- 轨迹、pickup、FLT 共存集成；
- EXCH2、旋转/曲线网格、LLC、cubed-sphere 或 OpenMP 生产支持。

## 3. 冻结的数据布局

为避免与现有每粒子诊断 `bomVEast/bomVNorth` 重名，P1.2 网格场固定命名为：

```text
bomGridUWork, bomGridVWork
bomGridVEast, bomGridVNorth
```

四个数组均为 `_RL`，形状固定为：

```text
(1-OLx:sNx+OLx, 1-OLy:sNy+OLy, 1, nSx, nSy)
```

前两个数组只保存传给 `ROTATE_UV2EN_RL` 的真实单层 C-grid 输入；后两个是 P1.2 权威 C 点 east/north 环境场。P1.2 不分配风或 Stokes 网格数组。

静态映射状态固定包括：

```text
bomMapXLo, bomMapXHi, bomMapYLo, bomMapYHi
bomMapXPeriod, bomMapTol
bomMapPeriodicX, bomFieldsReady
bomFieldTime, bomFieldIter
```

`bomFieldsReady` 在字段构造和两次 halo exchange 完成后才为真。插值不得读取未就绪场。

## 4. 冻结的例程接口

### 4.1 `BOM_INIT_MAPPING`

```text
BOM_INIT_MAPPING(myThid)
```

由 `BOM_INIT_FIXED` 调用。它使用 `xgOrigin/ygOrigin` 与全局 `delX(1:Nx)/delY(1:Ny)` 建立半开域 `[xLo,xHi) x [yLo,yHi)`，并核对所有间距为正、tile `xG/yG` 单调且域界一致。

仅当 `usingSphericalPolarGrid` 为真且全局 `sum(delX)` 在 `bomMapTol` 内等于 360° 时，`bomMapPeriodicX=.TRUE.`、`bomMapXPeriod=360°`。Cartesian 和非全球 spherical-polar 域不自动回绕。南北方向在 Phase 1 永不周期回绕。

`bomMapTol` 按 `_RL` 机器精度和比较量尺度计算，不使用固定米/度混合绝对容差。非有限、零/负间距或不一致域界立即停止。

### 4.2 `BOM_NORMALIZE_X`

```text
BOM_NORMALIZE_X(xx, xMap, isInsideX, myThid)
```

- 周期球面域把任意有限等价经度映射到 `[bomMapXLo,bomMapXHi)`；`xHi` 规范化为 `xLo`；
- 非周期域保持 `xMap=xx`，只在半开域内令 `isInsideX=.TRUE.`；
- 不修正纬度，不把域外 Cartesian 坐标夹到边界；
- 非有限输入返回失败，由调用者输出上下文并全局停止。

### 4.3 `BOM_MAP_XY2IJLOCAL`

```text
BOM_MAP_XY2IJLOCAL(
  xx, yy, bi, bj,
  xMap, ix, jy, isOwner, hasStencil,
  myThid)
```

语义：

- 先执行经度规范化，再在指定 tile 的 `xG/yG` 上建立局部分数索引；
- C 点为整数，U/V 面点为对应半整数，与 FLT 的索引约定一致；
- `isOwner` 只由 `[0.5,sNx+0.5) x [0.5,sNy+0.5)` 决定；
- `hasStencil` 独立表示 `floor(ix):floor(ix)+1`、`floor(jy):floor(jy)+1` 四个 C 点均在已交换 overlap 内；实现必须使用数学向下取整，不能直接用 Fortran 对负数向零截断的 `INT`；
- stage 位置可以 `hasStencil=.TRUE.` 而 `isOwner=.FALSE.`，但 P1.2 不改变 owner；
- 内部面和角点按半开规则归东/北侧 tile；不能用容差同时扩张两个 owner 区间；
- committed/initial owner 的全局候选数必须恰为 1，多 owner 或零 owner均为错误；stage stencil 可以在相邻 tile 重叠，但由当前 owner 调用。

### 4.4 `BOM_MAP_IJLOCAL2XY`

```text
BOM_MAP_IJLOCAL2XY(
  ix, jy, bi, bj,
  xx, yy, isValid,
  myThid)
```

规则网格按 `NINT(ix/jy)` 选择包含点的 face 区间并线性重建原生坐标。球面周期域返回规范化经度；往返测试比较规范化值，而不是要求保留输入的 ±360° 表示。索引需要的 face 超出 overlap 时返回失败，不外推。

### 4.5 `BOM_BUILD_FIELDS`

```text
BOM_BUILD_FIELDS(myTime, myIter, myThid)
```

执行顺序固定为：

1. 将海洋表层 `uVel/vVel` 的完整本地+halo 数据复制到 `bomGridUWork/bomGridVWork`；
2. 调用 `ROTATE_UV2EN_RL(...,.TRUE.,.TRUE.,.TRUE.,1,myThid)`；
3. 对 `bomGridVEast` 和 `bomGridVNorth` 分别调用标量 `EXCH_3D_RL(...,1,myThid)`；
4. 检查湿点输出有限、干点为零；
5. 写入 `bomFieldTime/bomFieldIter`，最后设置 `bomFieldsReady=.TRUE.`。

Phase 1 的表层固定为海洋 `k=1`，P1.2 明确拒绝 `usingPCoords`。例程只读 MITgcm 状态，不修改 `uVel/vVel`、mask 或 tendency。P1.2 的 `BOM_MAIN` 只允许构造/验证场，不推进粒子。

### 4.6 `BOM_INTERP_WET_PAIR`

```text
BOM_INTERP_WET_PAIR(
  ix, jy, bi, bj,
  fieldEast, fieldNorth,
  valueEast, valueNorth, wetWeight, isValid,
  myThid)
```

对 C 点场使用数学 `i1=floor(ix)`、`j1=floor(jy)` 和标准四点双线性权重。固定格式实现可先用 `INT`，再在截断结果大于原数时减 1；四个几何权重先按 `maskC(:,:,1)>0` 过滤，再除以共同的 `wetWeight`；两个分量必须逐位复用同一组归一化权重。

- `wetWeight >= bomWetWeightMin`、stencil 完整、输入/输出有限且字段已就绪时，`isValid=.TRUE.`；
- 常数湿场必须在舍入范围内保持常数；完整湿 stencil 的线性场必须达到双线性解析容差；
- 失败时返回 `isValid=.FALSE.` 和零输出，调用层用包含 tile、索引、湿权重的消息统一终止；
- P1.2 不把失败转为 `BOM_BEACHED`，也不做最近湿点、常数外推或坐标夹取。

## 5. P1.1 兼容与生命周期

- `BOM_LOCATE_INITIAL` 保留公共符号，内部改为调用 `BOM_MAP_XY2IJLOCAL`；
- 初值接受规则保持 P1.1 兼容：必须唯一 `isOwner`，且 owner 中心 `maskC(NINT(ix),NINT(jy),1)>0`；P1.2 不用四点湿权重悄悄放宽初值范围；
- `BOM_INIT_FIXED` 只初始化静态映射，不构造依赖海洋瞬时状态的速度场；
- `BOM_MAIN` 对零粒子立即返回；对非零粒子只构造 P1.2 字段和验证已有位置的映射/插值诊断，位置、状态、age 和 owner 数必须 bitwise 不变；
- P1.3 才接管 stage 位置、RHS、release 和运动。

## 8. 当前风险

- `ROTATE_UV2EN_RL` 的单层数组步长错误会在小型配置中隐藏，必须由多层 `Nr>1` 构建/运行覆盖；
- overlap-one 对四点 C stencil 足够，但必须显式检查，不能依赖越界后恰好可读；
- Fortran `INT` 对负分数向零截断；西/南 overlap 必须采用数学 floor，否则会错选相邻 C 点；
- 360° 周期判定只适用于全球规则球面域，区域球面算例必须保持开放边界；
- `angleCosC/angleSinC` 的人工旋转测试是单元级验证，不意味着 Phase 1 支持 `rotateGrid=.TRUE.`；
- P1.2 不提供运动证据，任何“轨迹正确”声明必须等到 P1.3。
